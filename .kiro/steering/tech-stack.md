## Dev Commands (from workspace root)

```bash
npm run dev:server    # nodemon server/src/index.js  -> port 3001
npm run dev:client    # vite                         -> port 5173
npm run build:client  # vite build -> client/dist/
npm run seed          # node server/src/seed.js (loads demo data)
```

## Environment Variables (`server/.env`)

| Key | Default | Purpose |
|---|---|---|
| PORT | 3001 | Server listen port |
| JWT_SECRET | fcat_secret | JWT signing secret |
| JWT_EXPIRES_IN | 7d | Token lifetime |
| DB_PATH | ./fcat.db | SQLite binary file location |
| UPLOADS_DIR | ./uploads | Proof file storage directory |
| NODE_ENV | — | Set to `production` to enable SPA serving |

## Notable Build Details

- Vite manual chunks: `react` (react+react-dom+router), `charts` (recharts), `pdf` (jspdf+autotable), `forms` (react-hook-form+axios)
- `chunkSizeWarningLimit: 1600` to silence recharts/jspdf size warnings
- Uploaded files live in `server/uploads/` — served at `/uploads/*` in dev via Vite proxy
- Database file `server/fcat.db` is binary — do not commit it; it is regenerated by `npm run seed`
